# About Us Builder

A simple responsive website for creating an About Us profile card.

## Inputs
- Image of yourself
- Full name
- Role
- School
- Grade
- Optional small bio
- Control for whether the bio is shown in the About Us preview

Profiles are saved in the browser's local storage. No data is sent to a server.

## Run locally
Open `index.html` in a browser, or use a static server such as `npx serve .`.
